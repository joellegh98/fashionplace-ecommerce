# Project Proposal Feedback

**Date:** 2026-06-12

FashionPlace is an eBay-style marketplace for jewelry and clothing. Users can post listings, browse items, add to cart, place orders, and leave reviews. An admin backend allows managing users and listings. All logic is server-side using Spring Boot MVC with Thymeleaf templates.
## My remarks

As we discussed earlier, the proposal looks ok, a classic website.
If you want to make it more complex, you could add more features and logic such as:

- Allow users to communicate with customer support through a messaging system.
- Implement a recommendation system that suggests products based on user preferences and purchase history.
- Implement a wishlist feature that allows users to save products for future purchase.
